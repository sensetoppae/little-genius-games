# จักรวาล WW RAUG East (GitHub Pages)

หน้านี้คือจักรวาลเต็มรูปแบบของทีม WW RAUG East ใช้ดูดวงดาว รายละเอียดงาน เพิ่มหรือแก้ข้อมูล และคุยด้วยเสียงในหน้าเดียว ไม่ต้องเปิดหน้า Apps Script แยก

ที่อยู่หลังเผยแพร่: https://sensetoppae.github.io/little-genius-games/ww-east/

## สิ่งที่ทำได้
- ดูจักรวาลทุกดวงดาว (ข้อมูลจากชีตชุดเดิม ผ่าน Apps Script)
- เปิดรายละเอียดดาว เพิ่มบันทึกประชุม เพิ่มนัดหมาย เพิ่มงาน Block FTTx เพิ่มหรือแก้เบอร์โทร
- คุยกับผู้ช่วย AI ด้วยข้อความหรือไมค์ (หน้านี้ใช้ไมค์ได้ เพราะไม่ได้อยู่ใน iframe ของ Apps Script)
- หน้าย่อยของแต่ละงานอยู่ที่ `dash.html?job=...` เช่น `dash.html?job=meetings` หรือ `dash.html?job=planwork`
- ดาว Planwork แสดงงานที่ครบกำหนดวันนี้และพรุ่งนี้ จากแท็บ schedule ในชีต Budget (อ่านอย่างเดียว)
- ดาว Check In มีปุ่ม 🗺️ เปิด Map เปิดแผนที่ Check In ในแท็บใหม่

## ตั้งรหัสผ่าน (จำเป็น)
หน้านี้ต้องมีรหัสก่อนถึงจะโหลดข้อมูลหรือแก้ไขได้

1. เปิดโปรเจกต์ Apps Script ของจักรวาล → ⚙️ การตั้งค่าโปรเจกต์ → Script Properties
2. เพิ่มชื่อ `DASH_PASSWORD` แล้วใส่รหัสที่คุณคิดเอง
3. วางไฟล์ `Code.gs` ชุดใหม่ (มี API แบบมีรหัส) แล้วกด Ctrl+S
4. ทำให้ใช้งานได้ → จัดการ → ✏️ → เวอร์ชันใหม่ → ทำให้ใช้งานได้

ห้ามพิมพ์รหัสในแชทหรือส่งให้คนอื่นในข้อความ

ครั้งแรกที่เปิดหน้าเว็บ จะมีฟอร์มให้ใส่รหัส รหัสถูกเก็บในเครื่องคุณเท่านั้น กด **ออกจากระบบ** เมื่อต้องการเปลี่ยนรหัสหรือล้างรหัสบนเครื่องนั้น

ถ้าเคยตั้ง `VOICE_API_KEY` ไว้ หน้าสรุป/ถาม/เสียงยังรับรหัสนั้นได้ แต่การดูข้อมูลครบและการเขียนต้องใช้ `DASH_PASSWORD`

## หลังอัปเดตโค้ด
วาง `Code.gs` ในโปรเจกต์ Apps Script แล้ว deploy เวอร์ชันใหม่ จากนั้นอัปเดตไฟล์ในโฟลเดอร์ `ww-east/` ของรีโพ GitHub (อย่าส่งรหัสขึ้นรีโพ)

ถ้าเปิดแล้วขึ้น 404 ให้รอ 1–2 นาที หรือกด Ctrl+F5

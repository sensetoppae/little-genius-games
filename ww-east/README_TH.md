# หน้าคุยด้วยเสียง "ศูนย์ควบคุม WW East" (GitHub Pages)

หน้าเว็บไฟล์เดียว (`index.html`) ใช้คุยกับผู้ช่วย AI ของแดชบอร์ด WW East ด้วยเสียงภาษาไทย
หน้า Apps Script ใช้ไมค์ไม่ได้ เพราะ Google เปิดหน้านั้นในกรอบ iframe ที่บล็อกไมโครโฟน หน้านี้จึงแยกออกมาไว้บน GitHub Pages ซึ่งเป็น https

## ใช้งาน
- แตะดวงอาทิตย์ หรือปุ่มไมค์ แล้วพูดภาษาไทย ถ้าติ๊ก "พูดจบแล้วส่งเลย" ไว้ พูดจบแล้วจะส่งคำถามทันที
- พิมพ์ถามได้ หรือกดปุ่มคำถามด่วน
- คำตอบแสดงเป็นข้อความและอ่านออกเสียง ใช้เสียงไทยในเครื่องก่อน ถ้าเครื่องไม่มี จะใช้เสียงไทยจาก Gemini ผ่าน Apps Script แทน
- ถ้าจะเพิ่มหรือแก้ข้อมูล ให้กดลิงก์ "เปิดแดชบอร์ดเต็ม / เพิ่ม-แก้ข้อมูล" (หน้า Apps Script เดิม)

## ตั้งค่า
- ลิงก์ /exec อยู่ในค่าคงที่ `EXEC_URL` บรรทัดแรกของ `<script>` ใน `index.html` ถ้า deploy Apps Script ใหม่จนได้ลิงก์ใหม่ ให้แก้ที่นี่ที่เดียว
- ต้อง deploy Apps Script เวอร์ชันที่มี `?api=summary|ask|tts` ก่อน หน้านี้จึงจะใช้ได้
- API อ่านอย่างเดียว ไม่มีการเขียนชีต จำกัดจำนวนครั้งต่อนาที และจำกัดคำถามไม่เกิน 500 ตัวอักษร
- ถ้าอยากล็อกไม่ให้คนอื่นใช้: ใน Apps Script ไปที่ ⚙️ การตั้งค่าโปรเจกต์ › Script Properties แล้วเพิ่ม `VOICE_API_KEY` = รหัสที่ต้องการ หน้าเว็บจะถามรหัสครั้งแรก แล้วจำไว้ในเครื่อง

## ข้อควรรู้
- ไมค์ใช้ได้บน Chrome / Edge (คอมและ Android) และ Safari บน iPhone รุ่นใหม่ ต้องกดอนุญาตไมโครโฟนครั้งแรก
- ถ้าขึ้นว่า "ไม่ได้รับอนุญาตให้ใช้ไมค์" ให้กดรูปกุญแจข้างช่องที่อยู่เว็บ แล้วเลือกอนุญาตไมโครโฟน
- ถ้าเสียงตอบเป็นสำเนียงอังกฤษ ให้ติดตั้งเสียงไทยใน Windows: Settings › Time & language › Speech
- หน้านี้มี `noindex` ไม่ให้ Google เก็บเข้าผลค้นหา แต่ใครมีลิงก์ก็เปิดได้ และ AI ตอบจากข้อมูลแดชบอร์ด รวมถึงเบอร์โทรในดาวข้อมูลติดต่อ ถ้าไม่อยากให้คนนอกถามได้ ให้ตั้ง `VOICE_API_KEY`
